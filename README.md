# Wellsy_Project

# 🏥 Wellsy (웰시)

### 임직원을 위한 통합 건강 관리 웹 플랫폼

**Wellsy**는 임직원이 자신의 건강 상태를 체계적으로 기록하고 관리할 수 있도록 지원하는 사내 건강 관리 웹 서비스입니다.

건강 기록, 운동 관리, 건강검진 정보 등을 한곳에서 관리할 수 있도록 구성했으며, AI 기반 헬스 코칭 및 운동 추천 기능을 통해 사용자에게 맞춤형 건강 관리 경험을 제공하는 것을 목표로 개발했습니다.

### 주요 기능

- **건강 기록 관리**: 사용자의 건강 데이터를 등록, 조회, 수정, 삭제하고 기록을 관리
- **AI 헬스 코칭**: AI를 활용한 건강 관련 상담 및 운동 추천 기능
- **운동 관리**: 운동 정보와 수행 기록을 관리하고 건강 관리를 지원
- **건강검진 관리**: 건강검진 정보와 예약 관련 기능 제공
- **건강 리포트**: 기록된 건강 데이터를 바탕으로 사용자의 건강 상태를 확인
- **사내 건강 관리**: 임직원 개인의 건강정보 보호를 고려한 관리 기능

### 기술 스택

- **Backend**: Java, Spring Boot, Spring Data JPA
- **Frontend**: React, JavaScript, HTML, CSS
- **Database**: MySQL
- **Infrastructure**: AWS EC2, AWS RDS, Docker
- **CI/CD**: GitHub Actions
- **Collaboration**: Git, GitHub

### 프로젝트 목표

건강 관리를 단순한 기록에서 끝내지 않고, 사용자가 자신의 건강 상태를 이해하고 꾸준히 관리할 수 있도록 돕는 서비스를 구현하는 것입니다.

또한 프론트엔드와 백엔드의 연동부터 데이터베이스 설계, 서버 배포까지 실제 웹 서비스의 개발 과정을 경험하는 것을 목표로 진행했습니다.
